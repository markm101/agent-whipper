Agent card: four directions

Each column is one direction, and each row is one state, so the columns compare like for like. Text in braces is a slot filled from the agent's data. Bars, dots, and the track are drawn from the same data. Every card answers, in order: does it need attention, is it getting closer, what is it doing, and how long is left. The rest moves to the agent page.

A. GlanceOne bar answers how close it is. Everything else moves to the agent page.
B. HeadlineA plain sentence says what is happening. Three numbers back it up.
C. TrackEach attempt sits on a line from start to target, so progress and history read together.
D. SectionsKeeps most of today's detail, in labeled rows with one color.
